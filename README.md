# Akademi Bilardo

Bodrum'da bulunan Akademi Bilardo'nun resmi web sitesi.

**Site:** [akademibilardo.com](https://akademibilardo.com)

## Teknoloji

- [Astro](https://astro.build) - Static site generator
- [Tailwind CSS](https://tailwindcss.com) - Styling
- GitHub Pages - Hosting
- GitHub Actions - CI/CD

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

`main` branch'ine push yapıldığında GitHub Actions otomatik olarak siteyi build edip GitHub Pages'e deploy eder.
